# 沉睡的龙：再拿一件，就走。

## v0.5 岩柱、古书与龙息

游戏更名《沉睡的龙》。新增两种大小不同的苔藓岩柱造型，以及可拾取的立体龙纹誓约古书（2 格、价值 8、重量 2.5）。场景共有 13 类物品、15 个生成点。

巨龙在玩家无掩护靠近 4.5 米内时苏醒；醒后在前方视野约 10 米范围内发现玩家，会锁定方向蓄力 1.4 秒，再喷火 1.25 秒，冷却 3.8 秒。喷火范围 9 米，每轮最多造成 1 点伤害，玩家有 3 点护甲。岩柱和具有碰撞的箱子可阻挡视线及火焰伤害；横移可以躲开已锁定的方向。诱饵可阻止新一轮蓄力，但不会取消已开始的攻击。出口安全圈不会受龙息伤害。护甲归零被抓，双人同伴可救援（恢复 1 点）。

待机画面单独降低雾量并加强补光；游戏场景新增暖色路灯，保留冷色雾和暗部。`additions.js` 为本版新增的岩石、古书和龙息模块，部署须包含全部文件。

验证：第一人称合同完成/撤离、俯视双人、古书拾取与丢弃、喷火蓄力/伤害/每轮单次命中/掩护/横移闪避/视野方向。


## v0.4 翡翠晶洞环境

按用户提供的青绿晶洞概念图调整环境：不规则分面岩壁、抬高洞顶、远端高耸晶簇、悬垂晶石、冷色雾与光束、粗糙连续地面。以实时 3D 风格化表现参考图的配色、纵深和明暗关系。保留原有灵龙、宝藏、交互和可通行路线。新增 `environment.js`，上传时需完整保留。

## v0.3 灵龙与宝藏美术更新

根据用户提供的 Spirit 动画与宝箱图片制作程序化 3D 造型：骨白面具、分叉黑角、蓝色身体、银色肩甲、青色灵焰鬃毛、蛇形尾巴及三团漂浮灵火。模型为风格化重建，不是参考作者的原始模型或原动画文件。

新增 8 组金币堆、6 个敞口金币箱，约 2,290 枚带边缘纹饰的实例化金币；周边金币与金币箱为场景陈设，不计入背包收益。两个原有可交互宝箱同步改为木板与蓝色铁箍造型。新增金币箱有碰撞，主路线和撤离点保持通行。

程序化美术位于 `art.js`，上传网页时必须包含此文件。

## v0.2 第一人称更新

单人默认第一人称，原有俯视双人模式保留。刷新网页即可加载新版。

- 鼠标转头：进入游戏自动锁定鼠标，直接移动鼠标转头；Esc 释放并暂停，点击底部按钮继续。若浏览器不支持锁定，直接在画面内移动鼠标或用方向键转头。
- WASD 相对视线行走，低头用准星对准三米内物品，E 拿取；出口按住 E 两秒撤离。
- Shift 冲刺：消耗体力、增加噪声；体力自动恢复，重载无法冲刺。
- Ctrl 静步，L 开关手持提灯，Q 丢弃，F 诱饵，R 静音袋。
- 新增两个可开盖宝箱：对准并按 E，开盖会发声；再次对准箱内物品按 E 拾取。
- 新增洞壁、洞顶、钟乳石、壁灯、提灯抬手反馈、出口方向与距离提示。
- 手机：画面拖动转头，虚拟方向键行走，动作按钮拾取和轻步。
- 双人仍采用原俯视操作，箱子自动打开，避免共用鼠标导致转头冲突。
- 第一人称不使用镜头摇晃；鼠标灵敏度固定，未实现跳跃、在线多人或VR。


基于《龙眠禁库 GDD v1.0》制作的浏览器可玩 MVP。Three.js 3D 场景、本地单人 / 同键盘双人、每局三分钟。不需要构建、注册或服务器接口。引擎已随包提供，不依赖在线 CDN。

## 本地游玩

完整解压文件夹，双击 `index.html`。不要只复制 HTML，`game.js`、`style.css` 和 `vendor` 都要保留。需要支持 WebGL 的现代浏览器。声音默认关闭，点击右上角开启。

## 上传到 GitHub Pages

1. 在 GitHub 创建一个仓库，例如 `dragon-vault`。
2. 选择 **Add file → Upload files**，上传本文件夹里的内容。确认 `index.html` 直接位于仓库根目录，`vendor/three.min.js` 保持原路径。
3. 提交到 `main` 分支。
4. 打开 **Settings → Pages → Build and deployment**，Source 选择 **Deploy from a branch**，Branch 选择 **main**，目录选择 **/(root)**，保存。
5. 等待 GitHub Pages 构建结束，访问 `https://你的用户名.github.io/dragon-vault/`。仓库名字不同，地址最后一段相应变化。

## 玩法

目标：成功带出至少两件关系遗物，合计价值达到 9，获得团队合同奖金 12。个人战利品分别结算。未撤离的物品不计分；可以提前空手撤离。

| 操作 | 玩家 1 | 玩家 2 |
| --- | --- | --- |
| 移动 | WASD | 方向键 |
| 拾取 / 翻找 / 救援 | E | Enter |
| 出口撤离 | 按住 E 两秒 | 按住 Enter 两秒 |
| 放下末件物品 | Q | Backspace |
| 轻步 | 左 Ctrl（第一人称也支持右 Ctrl） | 无独立轻步键 |
| 诱饵，一次，6 秒 | F | 右 Shift |
| 静音袋，一次，12 秒 | R | 右 Ctrl |
| 暂停 | Esc | Esc |

手机提供触屏按钮，仅单人。横屏更适合观察场景；桌面键盘是主要试玩方式。第一人称移动相对视线；俯视双人移动对应洞穴坐标。

每人三格背包；拿取前显示物品属性。怀表和木偶会周期发声，情书在快走时抖响，蛋糕逃跑，承诺罐丢下会碎。雕像占三格：单人拖得慢，两位活动玩家靠近 2.4 单位以内时携带者获得合作移速；这是邻近协作的简化模拟，并非双人刚体抓取。

警戒达到 35，龙检查最近声源；达到 75，永久追猎。入口光圈是安全撤离区。被抓的玩家可由仍在活动的同伴靠近救援；所有玩家都不再活动时立即结束。时间耗尽也会结算。

## 本版范围与改编

- 完整闭环：进入 → 搜刮 → 背包取舍 → 噪声升级 → 追逐 / 救援 → 撤离 → 结算 / 重玩。
- 12 类主题物品，14 个固定生成点；1 处纸堆翻找和 2 个开盖宝箱。
- 原 GDD 的 12 分钟压缩为 3 分钟，方便快速展览试玩。
- 原 GDD 的 VR / 1–4 人联机，改为网页单人 / 2 人同键盘。没有在线房间、VR 或麦克风采集。
- 低多边形模型、浮尘、噪声扩散圈、碎片与撤离粒子为程序生成。
- 物品交互、破碎和噪声是规则模拟；没有完整刚体堆叠、抛掷或真实声学。龙直接朝声源 / 玩家移动，不使用复杂导航，立柱仅阻挡玩家。
- 双人搬运、救援和个人收益可试玩；平衡数值仍需真实玩家测试，尤其是诱饵、雕像收益和追猎速度。
- 未实现商店、长线成长、随机地图、在线排行榜或存档。

## 建议试玩验证

先独自完成一单，再邀请朋友玩双人：

1. 前一分钟能否发现情书、放进背包并找到出口？
2. 面对占三格的雕像，是否愿意丢下已有战利品？
3. 怀表响起时，能否理解警戒增长的原因？
4. 是否愿意停下来帮同伴搬运 / 救援？
5. 是否有一次“再拿一件”和“现在就撤”的讨论？

结算记录噪声次数、主动丢弃次数、救援次数，并按实际行为显示短评。没有远程数据收集。
